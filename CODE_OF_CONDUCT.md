# Code of Conduct

## Our Pledge

We are committed to making this project welcoming, respectful, and inclusive for everyone.

## Expected Behavior

- Be respectful and considerate in communication.
- Welcome constructive feedback and differing viewpoints.
- Focus on the code, the issue, and the project goals.
- Help keep discussions friendly and productive.

## Unacceptable Behavior

- Harassment, discrimination, or hateful language.
- Personal attacks, insults, or intimidation.
- Deliberately disruptive or abusive conduct.
- Sharing private information without consent.

## Enforcement

Project maintainers may remove comments, close issues, or reject contributions that violate this code of conduct.

## Scope

This code of conduct applies to project discussions, pull requests, issues, and any related community spaces.

## Reporting

If you experience or witness unacceptable behavior, contact the project maintainers through the repository channels and provide as much context as possible.
